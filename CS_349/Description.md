# Course Description

CS349 investigates one of the fundamental engineering questions surrounding
knowledge-based systems:

How can an intelligent system determine what knowledge should be trusted?

Building upon reasoning (CS341), knowledge acquisition (CS342), machine
learning (CS346), and knowledge-based programming (CS347), students examine
the representation, measurement, validation, propagation, and maintenance of
certainty within intelligent systems.

Topics include certainty factors, Bayesian reasoning, evidential reasoning,
fuzzy logic, confidence propagation, explanation facilities, provenance,
knowledge validation, trust architectures, and enterprise decision support.

The course examines both deterministic and probabilistic approaches to
reasoning while introducing methods for evaluating trust within distributed
knowledge environments.

Students learn that intelligent systems must evaluate not only conclusions,
but also the reliability of the knowledge upon which those conclusions depend.

---

# Course Objectives

Upon successful completion students should be able to

- Explain the difference between truth, confidence, certainty, and trust.
- Compare deterministic reasoning with probabilistic inference.
- Evaluate knowledge provenance.
- Construct certainty models.
- Analyze conflicting evidence.
- Design trust architectures for distributed knowledge systems.
- Measure confidence propagation.
- Explain knowledge degradation over time.
- Validate enterprise knowledge sources.
- Design explainable decision-support systems.

# Learning Philosophy

Knowledge should never be accepted merely because it exists.

Every intelligent system must continually evaluate

- what it knows,
- where that knowledge originated,
- how much confidence it deserves,
- and whether circumstances have changed.

Trust is therefore not a property of individual rules.

It is an emergent property of an entire knowledge ecosystem.

# Modern Perspective

Modern enterprise AI systems operate across distributed data sources,
knowledge graphs, retrieval systems, autonomous agents, and human experts.

Although implementation technologies have changed dramatically, the
engineering question remains remarkably similar:

> Which knowledge should the system trust?

Students completing CS349 should recognize that trustworthy Artificial
Intelligence depends as much upon evaluating knowledge as upon generating
answers.
